# Java Full Stack Practice Repository

Welcome to the **Java Full Stack Practice Repository**! This repository is a curated collection of Java programs, organized day-wise, to help us build a strong foundation in Java programming and object-oriented concepts. It's designed for learning and aiming to enhance our skills in Java and prepare for full-stack development roles.

---

## 📁 Repository Structure

The repository is organized into directories named `DAY_1` through `DAY_9`, each containing Java programs that focus on specific topics:

- **DAY_1**: Introduction to Java, basic syntax, and simple programs.
- **DAY_2**: Control structures, loops, and conditional statements.
- **DAY_3**: Arrays, strings, and basic data structures.
- **DAY_3_oops**: Object-Oriented Programming concepts like classes and objects.
- **DAY_4**: Advanced OOP concepts such as inheritance and polymorphism.
- **DAY_5**: Exception handling and file I/O operations.
- **DAY_6**: Collections framework and generics.
- **DAY_7**: Multithreading and concurrency.
- **DAY_8**: GUI development with Java Swing.
- **DAY_9**: Introduction to JDBC and database connectivity.

Each directory contains Java files (`.java`) pertinent to the day's focus area.
